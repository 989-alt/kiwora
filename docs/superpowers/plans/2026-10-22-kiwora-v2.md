# 키워라! 식물 한살이 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v1 앱에 두 모드(매일/한 번에), 하루 넘김 장면, 단계별 돌보기(해야 다음 단계), 자·돋보기 관찰, 예보되는 날씨를 더하고 화분 위치·달 그림을 고친다. v1 저장과 짧은 코드는 그대로 읽힌다.

**Architecture:** 규칙은 모두 `src/sim/`의 순수 함수에 둔다. 돌보기 표·대기(`care.ts`), 시드 기반 날씨 일정·판정(`weather.ts`), 측정 보기(`measure.ts`)를 새로 만들고 `endDay`가 이들을 불러 판정한다. 저장은 `v: 1`을 유지한 채 새 필드를 선택 필드로 두고 `normalize`가 채운다(v1 식물 = 매일 키우기, 현재 단계 돌보기 완료). `store.ts` reducer가 모드·액션·하루 넘김 연출 신호(`nightFx`)를 다루고, UI는 장면 좌표(`SceneLayout`) 위에 돌보기·관찰 조작을 얹는다.

**Tech Stack:** Vite 6 + React 18.3 + TypeScript 5.9, Vitest 3 + @testing-library/react(jsdom), Playwright 1.64(galaxy-tab chromium / ipad webkit), lz-string, vite-plugin-pwa, Python(Pillow, numpy, pytest) 그림 파이프라인(kie.ai via education-pptx `image_gen.py`).

**Spec:** `docs/superpowers/specs/2026-10-22-kiwora-v2-design.md` (§9.5 결정 포함). 이 문서에 없는 규칙은 v1 스펙 `docs/superpowers/specs/2026-10-21-plant-life-design.md`을 따른다. 실행자는 계획과 함께 두 스펙을 읽는다.

## Global Constraints

- 상태판 용어와 5단계는 그대로: `매우 위험`/`위험`/`주의`/`적정`/`매우 좋음`, 행 이름 `물`/`햇빛`/`온도`/`영양`/`병충해`. 누적 피해 규칙(건강 ≥ 50에서 '매우 위험' 하루로는 죽지 않음)과 9종도 그대로.
- v1 저장 데이터(`plantlife.v1`, `v: 1`)와 짧은 기록 코드(24자 format 1, 25자 format 2)는 계속 읽힌다. 새 필드는 선택 필드, 기본값은 `normalize`가 채운다. `v`는 1로 둔다.
- v1 식물 = '매일 키우기'. v1 식물의 **현재 단계 돌보기는 완료로 간주**한다(업데이트 직후 갑자기 막히지 않게).
- 진행을 막는 퀴즈 팝업 금지. 돌보기·관찰은 장면 안 직접 조작이고, 보기 고르기는 장면 옆 패널(닫아도 진행에 영향 없음)이다.
- 해야 할 돌보기가 있으면 '오늘 할 일' 카드에 **항상** 보인다(밤 장면, 세로 화면, 1366×640 포함).
- 예보 없는 날씨 피해 금지: 날씨는 식물의 `weatherFrom`일(새 식물 2일째) 이후에만 오고, 전날 밤 장면·당일 아침 카드·상태판 '오늘의 날씨'·'오늘 할 일'에 보인다. 날씨만으로는 한 번에 죽지 않는다.
- 돌보기를 미루면 성장 점수는 다음 단계 기준(`STAGE_POINTS`=4)에서 멈춘다. 미룬 것 자체에는 피해가 없다.
- 짧은 코드에는 식물·모드·돌보기 진행·날씨 시드·도감만 담는다. '내가 잰 키'·'관찰한 것'은 긴 코드(`PL1-`)로만 보존한다.
- 한국어 UI 글자 ≥ 18px, 터치 영역 ≥ 48px, 3학년 수준 짧은 문장, 이모지 금지(코드·문구·그림 모두). 그림 안에 글자 금지.

## Review Focus

1. **업데이트 직후의 v1 저장(단계 중간, 물 준 하루 진행 중):** 매일 키우기로 열리고, 현재 단계 돌보기는 완료, 오늘은 날씨가 없다(`weatherFrom = day + 1`). 다음 [하루 마치기]에서 평소대로 다음 단계로 간다. → Task 3 `v1 plant loads as daily with its stage care done`, Task 6 `v1 save mid-stage keeps playing after the update`.
2. **두 모드 기록 섞임:** 매일로 완성한 봉숭아를 한 번에로 다시 완성하면 도감에는 한 번만, 일지는 최신 것, 배지는 최신 모드. 한 번에 식물은 날짜가 바뀌어도 자동 마감되지 않고, 한 번에 식물을 끝낸 같은 날 매일 식물을 새로 시작하면 1일째를 오늘 할 수 있다. → Task 6 `modes share the dex and the kept journal`, `a quick plant is never finalized by a new date`; Task 8 `badges follow the kept record's mode`.
3. **어떤 종·화면에서는 돌보기를 끝낼 수 없음:** 모든 (종, 돌보기 단계) × 6개 화면 크기에서 조작 목표가 장면 안에 있고 48px 이상이며 '오늘 할 일'·아침 카드에 가리지 않는다. 탭만으로도 끝낼 수 있다. → Task 9·10 `every care target is reachable on every viewport`, e2e `care can be finished by taps alone`.
4. **죽었거나 완성됐거나 옮겨 심기를 앞둔 식물의 날씨:** 죽은·완성 식물에는 예보·피해가 없다. 오늘 밤 옮겨 심기가 필요해진 나무는 내일 마당 기준 예보를 받고, 마당으로 옮긴 뒤에도 같은 날씨가 온다. → Task 4 `no weather for dead or finished plants`, `a tree about to be transplanted gets the yard forecast`.
5. **돌보기를 기다리는 식물을 짧은 코드로 복원:** 성장 4.0·돌보기 미완료가 그대로 돌아오고, '오늘 할 일'에 그 돌보기가 보이며, 하면 그날 [하루 마치기]에서 단계가 바뀐다. → Task 5 `format 3 keeps a plant waiting on its care`, Task 6 `restored waiting plant advances after its care`.

## 스펙 해석 (교사 확인 필요)

- 짧은 코드 "약 25자 유지": 모드·돌보기·날씨 시드·태풍 묶기를 손실 없이 더하면 127비트 + CRC 10이라 25자(115비트)에 들어가지 않는다. **28자(4자 × 7묶음)**로 한다.

- "씨 받으면 완성": 씨 받기는 열매 단계의 돌보기이고, 성장 점수도 차야 그날 [하루 마치기]에서 완성된다(일찍 따도 바로 끝나지 않음).
- 자 눈금: 그림 속 식물 크기는 단계로 정해지므로 '1cm 간격'이 날마다 달라진다(눈금이 그림 키 = 시뮬레이션 cm에 맞도록 늘었다 줄었다 함).
- 매일 키우기에서 죽은 뒤 [다시 심기]는 v1처럼 그날의 행동이라 씨 심기는 다음 날 한다.
