# 키워라! 식물 한살이 v2 — 설계 문서

- 작성일: 2026-10-22
- 상태: 검토 반영본 (교사 승인 대기)
- 기반: v1 설계 `2026-10-21-plant-life-design.md` (이 문서에 없는 규칙은 v1을 따른다)
- 현재 라이브: https://989-alt.github.io/kiwora/ (master 625f47b)

## 1. 목적과 이유

v1을 써 본 교사의 피드백:
1. 창가·그늘에 화분을 두면 화분 위치가 배경 그림과 맞지 않는다.
2. "내일 다시 만나요" 옆 아이콘을 달 일러스트로 바꾸고 싶다.
3. **할 수 있는 행동이 너무 적다.** 첫날 물 주기 말고는 할 일이 없고, 조작이 단조롭다.
4. **임의로 진행할 수 없다.** 현실 하루에 한 번만 진행되어 한 차시 안에 체험·시연할 수 없다.

v2의 목표: 매일 접속했을 때 할 일이 있고, 그 일이 한살이 단계와 교과 개념에 바로 연결되게 한다. 또 필요하면 한 번에 끝까지 키워 볼 수 있게 한다.

## 2. 교사가 정한 것

| 항목 | 결정 |
|---|---|
| 진행 방식 | **모드 두 개**: '매일 키우기'(현실 하루에 1일, v1과 같음) / '한 번에 키우기'(제한 없음) |
| 하루 넘김 연출 | [하루 마치기]를 누르면 해가 지고 밤(달·별)이 된다. 한 번에 키우기는 다시 해가 떠서 이튿날 아침이 시작된다. 매일 키우기는 밤에서 멈추고 달과 함께 "내일 다시 만나요"가 뜬다. 두 모드 모두 하루 넘김 장면이 있다. |
| 기록 | 두 모드 기록을 **같이 저장**한다. 어느 모드로 완성해도 씨 도감과 일지에 똑같이 남는다. |
| 새 활동 | **단계별 돌보기, 관찰·측정, 사건·날씨** 세 가지 |
| 단계별 돌보기 효과 | **해야 다음 단계로 넘어간다.** 성장 점수가 차도 그 단계의 돌보기를 하지 않으면 다음 단계로 넘어가지 않는다. |
| 측정 기록 | **자를 대고 눈금을 골라** 키를 잰다. 맞게 고르면 일지에 '내가 잰 키'로 기록된다. |
| 날씨 | **가끔(2~3일에 한 번), 미리 예보**한다. 전날 저녁 예보를 보고 대비하면 피해가 없다. |
| 그대로 두는 것 | v1의 상태판 용어(적정·병충해·영양), 5단계, 누적 피해 규칙, 9종 |

## 3. 고칠 것 (버그·그림)

### 3.1 화분 위치
- 창가·책상·그늘의 모든 배경에서, 화분 바닥이 그림 속 놓는 면(창턱·책상·선반) 위에 서 있어야 한다.
- 검증할 화면 크기: 1194×834, 1280×800, 1366×640, 1366×768, 820×1180, 768×1024.
- 원인은 배경을 화면에 맞춰 자를 때(cover) 놓는 면의 높이가 달라지는 것으로 보인다(추정). 해결은 만드는 사람이 정한다. 예: 배경별로 놓는 면의 범위를 다시 재서 화분 바닥을 그 범위 안에 고정하기, 놓는 면이 세로로 넉넉한 배경으로 다시 그리기.
- 각 화면 크기에서 스크린샷을 찍어 확인한다.

### 3.2 달 일러스트
- "내일 다시 만나요"와 [하루 마치기] 버튼의 달 아이콘을 클레이 스타일 **달 일러스트**로 바꾼다. 화분·벌레와 같은 스타일로 생성한다.
- 하루 넘김 장면의 밤하늘에도 같은 달을 쓴다.

## 4. 두 모드

- **고르는 곳:** 식물 고르기 화면에서 식물을 고른 뒤 "매일 키우기 / 한 번에 키우기"를 고른다. 모드는 식물마다 정해지고, 키우는 도중에는 바꿀 수 없다.
- **매일 키우기:** v1과 같다. 현실 날짜가 바뀌어야 다음 날이 된다.
- **한 번에 키우기:**
  - 날짜 제한이 없다. [하루 마치기]를 누르면 하루 넘김 장면 뒤 곧바로 다음 날 아침이 된다.
  - 일지의 날짜 칸은 'N일째'만 쓴다.
- **두 모드 공통:** 아침 소식 카드, 상태판, 누적 피해, 사망, 씨 도감이 모두 같다. 일지와 도감에는 모드 표시(작은 배지)를 붙인다.
- **하루 넘김 장면:**
  - 약 2.5초. 해가 지고 하늘이 어두워지며 달·별이 뜬다. 한 번에 키우기는 이어서 해가 뜬다.
  - 화면을 탭하면 건너뛸 수 있다.
  - 움직임 줄이기 설정(prefers-reduced-motion)이면 짧은 페이드로 바꾼다.

## 5. 단계별 돌보기 (해야 다음 단계로)

각 단계에 **그 시기에만 하는 돌보기**가 하나 있다. 성장 점수가 다음 단계 기준을 넘어도 돌보기를 마치기 전까지는 단계가 바뀌지 않는다.
- 피해는 없다. 화면에 할 일 알림("꽃가루를 옮겨 줘야 열매가 열려요")이 뜬다.
- 아침 카드와 상태판 근처에 오늘의 할 일 카드로 보인다.

| 단계 | 돌보기 | 조작(제안) | 교과 연결 |
|---|---|---|---|
| 씨 (1일째) | **씨 심고 흙 덮기**: 씨 2~3알을 흙에 놓고 손가락으로 흙을 덮는다 | 씨를 끌어 화분에 놓고 문질러 덮기 | 씨를 심는 방법 |
| 싹 | **솎아내기**: 여러 개 난 싹 중 약한 싹을 뽑아 하나만 남긴다 | 약한 싹 탭 | 식물이 잘 자라는 조건(공간·영양) |
| 잎과 줄기 | 종별: 나팔꽃 **지지대 세우고 덩굴 감기**, 강낭콩 **지지대 세우기**, 벼·옥수수 **포기 사이 흙 북돋우기**, 봉숭아 **곁가지 정리**, 여러해살이 **물 빠짐 확인** | 지지대 끌어 꽂기 등 | 줄기의 생김새·감는 줄기 |
| 적당한 크기(여러해살이) | 옮겨 심기(v1과 같음) + 나무는 **가지치기** | 마른 가지 탭 | 나무의 성장 |
| 꽃 | **꽃가루 옮기기**: 붓으로 꽃의 꽃가루를 다른 꽃에 묻힌다. 벼·옥수수는 **포기를 흔들어 꽃가루 날리기** | 꽃 → 꽃 끌기 / 흔들기 | 꽃이 지고 열매를 맺음 |
| 열매 | 한해살이 **열매 따서 씨 받기**(씨 받으면 완성). 여러해살이 **열매 따기** | 열매 탭 → 씨 꺼내기 | 열매 속 씨 → 다시 한살이 |
| 겨울(여러해살이) | **겨울 준비**: 나무는 줄기에 짚 감싸기, 민들레는 화분을 책상 쪽으로 | 끌기 | 여러해살이식물의 겨울나기 |

- 돌보기 화면은 진행을 막는 퀴즈가 아니다. 장면 안에서 직접 조작한다(v1 반목표 유지).
- 정확한 조작 방식과 그림은 만드는 사람이 정한다. 필요한 그림(씨 알·붓·지지대·짚·가위 등)은 기존 클레이 스타일로 생성한다.

## 6. 관찰·측정 (자로 재고 눈금 고르기)

- 매일 한 번 **[관찰하기]**를 할 수 있다. 선택 활동이지만 하면 일지가 채워진다.
  1. **키 재기:** 화면 속 자를 식물 옆으로 끌어다 대고, 눈금을 읽어 보기 3개 중 하나를 고른다. 맞으면 '내가 잰 키 N cm'가 일지에 기록되고, 틀리면 "다시 보아요"와 함께 한 번 더 기회를 준다.
  2. **돋보기:** 잎·꽃·열매 부분을 확대해 보고, 관찰 문장 보기(예: "잎 가장자리가 톱니 모양이에요") 중 맞는 것을 고른다. 골라진 문장이 일지의 '관찰한 것' 칸에 들어간다.
- 자의 눈금은 그림 속 식물의 실제 키(cm, 시뮬레이션 값)와 맞아야 한다. 화면의 식물 크기와 자 눈금을 연동한다.
- 관찰 문장은 종·단계별로 미리 준비한다(9종 × 단계). 교과서 수준의 사실만 쓰고 만드는 사람이 작성한다.
- 일지 표에 '내가 잰 키', '관찰한 것' 열을 추가한다. 인쇄 일지에도 나온다.

## 7. 사건·날씨 (가끔, 미리 예보)

- 2~3일에 한 번 날씨 사건이 생긴다. **전날 [하루 마치기] 직후(밤 장면)와 다음 날 아침 전에** 예보 카드로 알린다. 예: "내일은 아주 더워요! 창가는 뜨거울 거예요."
- 대비하면 피해가 없고, 대비하지 않으면 그날 해당 조건이 나빠진다(상태판에 반영). 한 번에 죽지는 않는다(v1 누적 피해 규칙 그대로).

| 날씨 | 대비 | 대비하지 않으면 |
|---|---|---|
| 폭염 | 화분을 창가에서 책상·그늘로 / 물 넉넉히 | 창가 온도 매우 높음, 물 증발 2배 |
| 비 오는 날(마당 식물) | 물 주지 않기 | 물 과다 |
| 장마(2~3일 연속 비) | 물 주지 않기, 벌레 살피기 | 물 과다, 벌레 확률↑ |
| 태풍(마당 나무) | 지지대·끈 묶기 | 건강 감소 |
| 쌀쌀한 날·서리 | 창가에서 안쪽으로 / 겨울 준비 | 온도 낮음 |

- 날씨는 계절감에 맞게 단계와 엮는다(예: 겨울 단계에는 서리, 꽃·열매 무렵에는 장마·태풍). 구체 확률·수치는 만드는 사람이 정한다.
- 한 번에 키우기에서도 같은 규칙이고, 예보는 밤 장면에서 보인다.

## 8. 비목표·반목표

- **비목표:** 새 식물 종 추가, 서버·로그인, 교사 현황판.
- **반목표:**
  - 진행을 막는 퀴즈 팝업.
  - 돌보기를 몰라서 영원히 멈추는 것. 해야 할 일은 항상 화면에 보여야 한다.
  - 날씨 예보 없이 갑자기 당하는 피해.
  - 매일 키우기 학생의 기존 기록이 사라지는 것. v1 저장 데이터와 짧은 기록 코드는 그대로 읽혀야 한다.

## 9. 기술 제약

- v1 저장 데이터와 호환된다. 새 필드는 선택 필드로 두고 `v: 1`을 유지하며, 기본값은 normalize에서 채운다.
- v1 식물은 '매일 키우기'로 간주한다.
  - v1 식물이 이미 단계 중간이면, 그 단계의 돌보기는 '완료'로 간주한다. 업데이트 직후 갑자기 막히는 일이 없게 하기 위해서다.
- 짧은 기록 코드에 모드와 돌보기 진행 상태를 담을 수 있어야 한다. 새 형식 버전을 추가하고, 이전 형식(24·25자)도 계속 읽는다.
- 그림은 기존 파이프라인(kie.ai, scripts/gen_assets.py)으로 생성하고, 앵커를 측정한다.
- 배포는 GitHub Pages(`npm run build:pages` → gh-pages)로 한다.
- 오프라인 프리캐시가 지나치게 늘지 않게 한다(새 그림 webp 최적화).

## 9.5 추가 결정 (검토 후)

**교사 결정**
- **출시:** 한 번에 모두 만든 뒤 한 번 배포한다.
- **짧은 기록 코드 범위:** 식물·모드·돌보기 진행 상태·도감만 담는다(약 25자 유지). '내가 잰 키'·'관찰한 것'은 전체 코드(복사)로만 보존한다.

**만드는 사람의 판단 (교사 확인 전, 바꿔도 됨)**
- **날씨 흐름:**
  - 날씨는 '그날' 적용된다. 전날 밤 장면에서 "내일은 ○○"이라고 예보한다.
  - 날씨 당일 아침 카드에 "오늘은 ○○! ~해요"를 다시 보여 준다. 학생은 그날 낮에 대비 행동을 하고, 판정은 그날 [하루 마치기] 때 한다.
  - 매일 키우기 학생도 아침에 보고 대비할 수 있다. 상태판에 '오늘의 날씨' 칸을 둔다.
- **날씨 일정:** 식물마다 시작할 때 시드를 정하고, 그 시드로 날씨 일정을 결정적으로 만든다. 같은 식물이면 복원 후에도 같은 날씨가 온다. 시드는 짧은 코드에 넣는다. 교사가 미리 볼 수 있는 기능은 없다.
- **돌보기를 미룬 경우:**
  - 성장 점수는 다음 단계 기준에서 멈춘다(넘치지 않음). 날은 계속 흐르고, 물·햇빛 등 상태 판정과 누적 피해는 평소대로 적용된다. 돌보기를 미룬 것 자체에는 피해가 없다.
  - 완성 일수는 늘어날 수 있다(한해살이 '약 10일'은 모든 돌보기를 제때 했을 때 기준). 일지에는 실제 일수를 적는다.
- **돌보기 순서:**
  - 한 단계에 돌보기가 여러 개면 표의 순서대로 모두 필수다. 예: 여러해살이 '적당한 크기'는 옮겨 심기 → 가지치기.
  - 날씨 대비는 단계 돌보기가 아니어서 단계 진행과 무관하다.
  - 씨 단계는 '씨 심고 흙 덮기'를 먼저 하고 물 주기를 한다. 첫날 안내 말풍선도 이 순서에 맞춘다.
- **측정 오답:** 두 번 틀리면 정답 눈금을 강조해 보여 주고, 학생이 그 눈금을 눌러야 기록된다. 기록에는 '도움 받음' 표시를 남긴다. 한 번에 키우기에서도 '하루 한 번'이 기준이다(날마다 다시 할 수 있음).
- **도감·일지 필터:** 모드 배지 외에 따로 필터나 통계는 두지 않는다.

## 10. 만드는 사람에게 맡기는 것

- 각 돌보기·측정·날씨의 조작 세부, 애니메이션, 수치(확률·효과 크기)
- 관찰 문장 작성(교과서 수준 사실, 종·단계별)
- 새 그림 목록과 프롬프트
- 화분 위치 문제의 구체 해결 방법
